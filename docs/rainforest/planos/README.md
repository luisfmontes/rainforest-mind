# Planos de implementacao

Um arquivo por trabalho, escrito pela skill `plano` a partir do design aprovado:
`AAAA-MM-DD-<tema>.md`. Cada tarefa declara **de que outra depende** e se e
**paralelizavel** — e essa marcacao que o estagio `executar` usa para despachar
em paralelo, sem adivinhar.

Criterio de pronto por tarefa e **falsificavel**: comando exato e saida esperada.
Tarefa com "a definir" nao entra — o plano volta para o brainstorm.

Versionado de proposito — ver `../README.md`.
